# General guidelines

* Only use absolute positioning when necessary. Opt for responsive and well structured layouts that use flexbox and grid by default
* Refactor code as you go to keep code clean
* Keep file sizes small and put helper functions and components in their own files.

# Design system guidelines

## Text
* Use a base font-size of 1rem
* Use a minimum font-size of .78rem
* All text is the colour #222425

## Colour and transparency
* Radial Menu background colour #F2F2F2 & transparency 88% 
* Radial Menu close button background colour #F2F2F2 & transparency 56%
* Prompt Field background colour #F2F2F2 & transparency 88% 
* Prompt Field close button background colour #F2F2F2 & transparency 56%

## Radius
* All elements have a radius of 100

## Responsiveness
Responsive behaviour ensures components adapt fluidly to available space and input length.
* Prompt field Max width of 632px
* Prompt field Min width of 460px

## Button
The Button component is a fundamental interactive element in our design system, designed to trigger actions or navigate
users through the application. It provides visual feedback and clear affordances to enhance user experience.
* Primary button background colour #814EFA
* Primary icon colour #FFFFFF
* Secondary Button has no background colour
* Secondary Button icons #222425
